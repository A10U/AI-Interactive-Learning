# Chapter 5: การสั่งอาหารและเครื่องดื่มเฉพาะทาง (Specialty Food & Drinks)

*ส่วนขยายของ Master Plan (ต่อจาก Chapter 1: การสั่งอาหารทั่วไป)*

## 1. วัตถุประสงค์

ฝึกสื่อสารในร้านที่มี**ศัพท์และขั้นตอนเฉพาะ**ซึ่งพบบ่อยในชีวิตจริง (ร้านเบเกอรี, ร้านอาหารต่างชาติ, ร้านน้ำผลไม้/มัทฉะ, บาร์)
และฝึก**มุมมองของผู้ให้บริการ**ผ่านโหมดสลับบทบาท ซึ่งเป็นทักษะสำหรับการฝึกงานหรือทำงานพาร์ทไทม์ในร้านอาหาร

## 2. Learning Scenarios

| Scenario | โจทย์ | Multimodal Focus |
|---|---|---|
| **5.1 ร้านเบเกอรี** | สั่งขนม ตอบคำถามปลายเปิด (อุ่นไหม, ทานที่ร้านไหม), สั่งเค้กวันเกิดทั้งปอนด์พร้อมเทียน/กล่องของขวัญ | ชี้ขนมในตู้ + พูดตอบคำถามสั้นๆ |
| **5.2 อาหารนานาชาติ** | ใช้ศัพท์เฉพาะ: ความสุกสเต๊ก (Rare – Well done), ซุปราเมง/ความนุ่มเส้น, ขนาดถาดพิซซ่า, ความเผ็ดแกงอินเดีย | พิมพ์/พูดคำศัพท์ต่างประเทศ + ติ๊กตัวเลือก |
| **5.3 น้ำผลไม้และมัทฉะ** | ปรับแต่งละเอียด: น้ำแข็ง, ความหวาน, ความเข้มมัทฉะ, นมทางเลือก (แพ้นม/ถั่ว), ท็อปปิ้ง | ติ๊ก Checkbox + พูดตอบคำถามสั้น (เช่น "น้อย") |
| **5.4 ค็อกเทลและม็อกเทล** | ยืนยันอายุ 20+ ด้วยบัตร, บอกอายุตามจริง, เลือกเวอร์จิ้น/ม็อกเทลเมื่ออายุไม่ถึงหรือต้องขับรถ | การ์ด AAC "แสดงบัตรประชาชน" + พูด |

## 3. โหมดสลับบทบาท (Role Swap)

```
[AI ลูกค้า] มีออเดอร์ในใจ (+ อาจแพ้อาหาร / อายุไม่ถึง) ──บอกบางส่วน──► [ผู้เรียน = พนักงาน]
                                                              │ ทักทาย / ถาม / ตรวจบัตร / ทวน / คิดเงิน
                                                              ▼
                                                  [ลูกค้าตอบตามจริง: ตอบคำถาม, แก้เมื่อทวนผิด, ทักเมื่อราคาผิด]
                                                              │
                                                              ▼
                                  [Coach ฝั่งพนักงาน] ถามครบไหม · ถามซ้ำไหม · ทวนถูกไหม · ราคาถูกไหม · ดูแลความปลอดภัยไหม
```

เกณฑ์ประเมิน: ออเดอร์ถูกต้อง · ประสิทธิภาพ (จำนวนเทิร์น/การถามซ้ำ) · การคิดราคา · ความสุภาพ · ความปลอดภัย/กฎหมาย

## 4. หลักความปลอดภัยที่ระบบบังคับเสมอ (ไม่พึ่ง LLM)

- **อาการแพ้:** งดวัตถุดิบที่เอาออกได้ให้อัตโนมัติ และปฏิเสธเมนูที่มีสารก่อภูมิแพ้เป็นส่วนผสมหลัก
- **แอลกอฮอล์:** ต้องยืนยันอายุก่อนเสิร์ฟ ใช้อายุจากบัตร (โปรไฟล์) ไม่ใช่อายุที่ผู้เรียนพูด ถ้าอายุต่ำกว่า 20 ปีจะเปลี่ยนเป็นเวอร์จิ้น หรือแนะนำม็อกเทลแทน
