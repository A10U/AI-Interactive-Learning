# 🥐 Specialty Ordering — Chapter 5: สั่งอาหารและเครื่องดื่มเฉพาะทาง

ต่อยอดจาก Chapter 1 (ใช้ระบบเดียวกัน) เพิ่ม 4 สถานการณ์ใหม่ + **โหมดสลับบทบาท (ผู้เรียนเป็นพนักงาน)**
รองรับ **ภาษาไทย / English** · สื่อสารได้ทั้ง **พูด 🎤 · พิมพ์ ⌨️ · ชี้เมนู 👉 · ติ๊กตัวเลือก ☑️ · การ์ด AAC 🗂️**

## 4 สถานการณ์

| สถานการณ์ | ฝึกอะไร | ตัวอย่างประโยค |
|---|---|---|
| 🥐 **5.1 ร้านเบเกอรี** | อุ่นไหม · ทานที่ร้าน/กลับบ้าน · ชิ้น/ทั้งปอนด์ · เทียน/กล่องของขวัญ · แพ้ถั่ว/นม/ไข่ | *"ขอครัวซองต์อัลมอนด์ อุ่นให้หน่อย ทานที่ร้านค่ะ"* |
| 🌏 **5.2 อาหารนานาชาติ** | ราเมง (ซุป, ความนุ่มเส้น) · สเต๊ก/เบอร์เกอร์ (ความสุก) · พิซซ่า (ถาด, แป้ง) · แกงอินเดีย · บิบิมบับ | *"Ribeye medium rare, black pepper sauce on the side, with salad"* |
| 🍵 **5.3 น้ำผลไม้และมัทฉะ** | น้ำแข็ง · ความหวาน · ความเข้มมัทฉะ · นมทางเลือก · ท็อปปิ้ง · ไม่รับหลอด | *"มัทฉะลาเต้เย็น นมโอ๊ต หวานน้อย เข้มข้นครับ"* |
| 🍹 **5.4 ค็อกเทลและม็อกเทล** | **ยืนยันอายุ 20+ ด้วยบัตร** · เวอร์จิ้น/ไม่มีแอลกอฮอล์ · ขอบแก้ว · ปั่น/ออนเดอะร็อค | *"ขอโมจิโต้แบบมีแอลกอฮอล์ หวานน้อยครับ"* → *"นี่ครับบัตรประชาชน"* |

**กลไกการตรวจบัตร (5.4):** ถ้าออเดอร์มีแอลกอฮอล์ พนักงานจะขอดูบัตรก่อนทวนออเดอร์ บัตรแสดง**อายุจริงจากโปรไฟล์ภารกิจ** ไม่ใช่อายุที่ผู้เรียนพูด
- ถ้าผู้เรียนบอกอายุไม่ตรงความจริง โค้ชจะจับได้
- ถ้าอายุต่ำกว่า 20 ปี พนักงานจะเปลี่ยนเป็นแบบเวอร์จิ้นให้ หรือแนะนำม็อกเทลแทน
- ภารกิจ "ต้องขับรถกลับบ้าน" ต้องเลือกเครื่องดื่มที่ไม่มีแอลกอฮอล์เอง

## 🔄 โหมดสลับบทบาท: คุณเป็นพนักงาน

เลือก **โหมด → "เป็นพนักงาน (สลับบทบาท)"** แล้ว AI จะเป็น**ลูกค้า** ที่มีออเดอร์ในใจ แต่บอกไม่หมดตั้งแต่แรก หน้าที่ของคุณ:

1. **ทักทาย** → 2. **ถามรายละเอียดให้ครบ** (ถามหลายเรื่องในประโยคเดียวได้คะแนนดี / ถามซ้ำเรื่องที่ลูกค้าบอกแล้วเสียคะแนน)
3. **ดูแลความปลอดภัย:** ลูกค้าบางคนแพ้อาหาร ต้องยืนยันว่า "จะไม่ใส่…ให้" / ในบาร์ต้อง**ขอดูบัตร** ถ้าอายุไม่ถึง 20 ปีต้องปฏิเสธอย่างสุภาพและเสนอเวอร์จิ้น
4. **ทวนออเดอร์:** ถ้าผิดหรือขาด ลูกค้าจะแก้ให้ → 5. **บอกราคาให้ถูก:** คิดเองจากป้ายเมนู ซึ่งแสดงราคาตัวเลือกเสริมไว้ให้

ตัวช่วย: **ใบจดออเดอร์** แสดงสิ่งที่ลูกค้าบอกแล้ว ("?" คือยังไม่ได้ถาม) · **ปุ่มประโยคสำเร็จรูป** ใต้ช่องพิมพ์ · แตะเมนูเพื่อใส่ชื่อเมนูลงช่องพิมพ์
หน้าสรุปผลให้คะแนน: ออเดอร์ถูกต้อง · ประสิทธิภาพ · คิดราคา · ความสุภาพ · ความปลอดภัย/รับผิดชอบ

> โหมดสลับบทบาทใช้ลูกค้าแบบ Offline (rule-based) เสมอ ส่วนโหมดลูกค้าปกติใช้ Claude ได้ถ้าตั้ง API key

## 💡 ตัวช่วย (Assist Bot) — เมื่อคุยกับ AI แล้วติด

กดปุ่ม **💡 ตัวช่วย** ข้างไมค์ ใช้ได้ทั้งโหมดลูกค้าและโหมดพนักงาน แผงตัวช่วยมีดังนี้
- **🧭 ตอนนี้:** บอกว่าอีกฝ่ายถามอะไรอยู่ หรือเราควรทำอะไรต่อ พร้อมคำเตือน เช่น ยังไม่ได้แจ้งว่าแพ้อาหาร, ต้องขับรถ, ออเดอร์ไม่ตรงภารกิจ
- **📖 คำศัพท์:** อธิบายศัพท์เฉพาะในประโยคล่าสุดเป็นไทย/อังกฤษ เช่น มีเดียมแรร์, เวอร์จิ้น, On the rocks, ทงคตสึ
- **💬 ลองพูดแบบนี้:** ประโยคตัวอย่างที่ทดสอบแล้วว่า AI เข้าใจ แตะเพื่อใส่ลงช่องพิมพ์ หรือกด 🔊 เพื่อฟังแล้วพูดตาม (⭐ = ตรงกับภารกิจ)
- **🎯 ประโยคเต็ม (เฉลย):** ซ่อนไว้ก่อน กดดูเองเมื่อต้องการ · **🧮 วิธีคิดราคา** (โหมดพนักงาน) · **🐢 ฟังอีกครั้งแบบช้าๆ**
- เลือกคำลงท้าย **ครับ/ค่ะ** ของตัวเองได้

ถ้าติดหลายเทิร์นติดกัน ระบบจะช่วยเอง: ติด 2 เทิร์นปุ่มจะกะพริบ ติด 3 เทิร์นแผงตัวช่วยจะเปิดให้อัตโนมัติ
หน้าสรุปผลจะแสดงจำนวนครั้งที่ใช้ตัวช่วย แต่ไม่หักคะแนน ตัวช่วยทำงานแบบ Offline เสมอ จึงตอบทันทีโดยไม่ต้องใช้ API key

## วิธีรัน

ดับเบิลคลิก **`start.bat`** หรือเปิด Terminal ในโฟลเดอร์นี้แล้วรัน `node server.js` จากนั้นเปิด **http://localhost:3000** ด้วย Chrome หรือ Edge
ไม่ต้องติดตั้งอะไรเพิ่ม ถ้า Chapter 1 เปิดอยู่ที่ port 3000 ให้ปิดก่อน หรือรัน `$env:PORT=3001; node server.js` (PowerShell)

**ใช้ Claude (ไม่บังคับ):** `npm install` แล้ว `$env:ANTHROPIC_API_KEY="sk-ant-..."` จากนั้น `node server.js`
ระบบกันอาหารที่แพ้และระบบตรวจอายุทำงานฝั่ง server เสมอ ไม่ให้ Claude ตัดสินเอง

**ทดสอบ:** `npm test` (16 กรณี ครอบคลุมทั้ง 4 สถานการณ์และโหมดสลับบทบาท)

## โครงสร้างโปรเจกต์

```
server.js               Orchestrator — /api/config, /api/turn, /api/debrief, /api/customer/start, /api/customer/turn
src/scenarios.js        Domain Ontology: 4 สถานการณ์, เมนู, ตัวเลือก, วัตถุดิบ, สารก่อภูมิแพ้, ภารกิจ (+ โปรไฟล์อายุ/ขับรถ)
src/order.js            Order State: Slot Filling, ราคา (รองรับราคาเฉพาะเมนู), ตรวจอาการแพ้, ตรวจแอลกอฮอล์
src/nlu.js              Intent & Slot Extractor ไทย/อังกฤษ (+ อายุ, การยื่นบัตร)
src/aggregator.js       Context Aggregator: พูด + พิมพ์ + ชี้ + ตัวเลือก + การ์ด AAC (แพ้อาหาร / แสดงบัตร)
src/actorEngine.js      Actor Agent (พนักงาน AI) + Safety Guard + Age Guard + State Machine ทวน/ยืนยัน
src/coachEngine.js      Coach Agent: ประเมินรายเทิร์น (+ ความซื่อสัตย์เรื่องอายุ, การดื่มอย่างรับผิดชอบ)
src/customerEngine.js   โหมดสลับบทบาท: ลูกค้า AI + Coach ฝั่งพนักงาน + สรุปผลการขาย
src/llmEngine.js        Actor + Coach ด้วย Claude (ตัวเลือก)
src/debrief.js          สรุปผลโหมดลูกค้า
public/                 หน้าเว็บ
test/                   ชุดทดสอบ
```

## เพิ่มเมนู / สถานการณ์เองได้

แก้ไฟล์เดียวคือ `src/scenarios.js`:
- เพิ่มเมนูในรายการ `..._MENU`
- เพิ่มตัวเลือกใหม่ใน `GROUPS` (ใส่คำที่ลูกค้าอาจพูดใน `kw`)
- เพิ่มภารกิจใน `missions`

ระบบพนักงาน โค้ช ลูกค้า AI และหน้าเว็บจะรองรับให้อัตโนมัติ
