# 🍽️ AI Food Ordering — Chapter 1: การสั่งอาหารทั่วไป (General Food Ordering)

ขยายผลจาก Chapter 0 (ร้านกาแฟ) ตามเอกสาร `../Documents/AI Interactive Learning Master Plan` หัวข้อ 3
รองรับ **ภาษาไทย / English** และสื่อสารได้ 4 ช่องทาง: **พูด 🎤 · พิมพ์ ⌨️ · ชี้เมนู 👉 · ติ๊กตัวเลือกย่อย / การ์ด AAC ☑️**

## 3 สถานการณ์ (Scenario 1.1 – 1.3)

| สถานการณ์ | โจทย์ | Multimodal Focus |
|---|---|---|
| ☕ **1.1 คาเฟ่และเบเกอรี** | สั่งเครื่องดื่ม: ชนิด, ร้อน/เย็น/ปั่น, **ประเภทนม**, ความหวาน, ไซส์ + เบเกอรี/ของเพิ่ม | ชี้เมนูบนแท็บเล็ต + พูดบอกระดับความหวาน |
| 🍳 **1.2 ร้านอาหารตามสั่ง** | "กะเพราหมูสับ ไม่ใส่ถั่วฝักยาว เผ็ดน้อย พิเศษไข่ดาวสุกๆ" | พิมพ์ / ติ๊ก Checkbox Modifiers + **พูดทวนออเดอร์** |
| 🩺 **1.3 แพ้อาหาร / ข้อจำกัดด้านสุขภาพ** | แจ้งแพ้ถั่วลิสง / อาหารทะเล / ไข่, ถามส่วนผสม, ขอเปลี่ยนวัตถุดิบ (แซลมอน → ซาบะ) | สื่อสารเรื่องสุขภาพ + ยืนยันความปลอดภัยกับพนักงาน |

## วิธีเล่น

1. ดับเบิลคลิก **`start.bat`** หรือรัน `node server.js` (Node.js 18 ขึ้นไป ไม่ต้องติดตั้งอะไรเพิ่ม ไม่ต้องมี API key)
2. เปิด **http://localhost:3000** ด้วย Chrome หรือ Edge (ปุ่มไมค์ใช้ Web Speech API)
3. เลือกสถานการณ์จากแท็บด้านบน แล้วลองสั่งได้เลย เช่น
   - 1.1: แตะ **ลาเต้ → เย็น** แล้วพูด *"หวานน้อยแก้วหนึ่งครับ"*
   - 1.2: พิมพ์ *"กะเพราหมูสับ ไม่ใส่ถั่วฝักยาว เผ็ดน้อย พิเศษไข่ดาวสุกๆ ครับ"* → พนักงานทวน → ทวนกลับหรือตอบ *"ถูกต้องครับ"*
   - 1.3: แตะ **ข้าวผัดกระเทียมแซลมอน** + พูด *"ขอเปลี่ยนเป็นปลาซาบะย่างแทน ไม่ใส่ต้นหอม"* + ติ๊ก ☑️ แยกน้ำจิ้ม ☑️ ไม่ใส่ผักชี
   - 1.3: *"ผมแพ้ถั่วลิสงครับ ผัดไทยมีถั่วไหม"* หรือแตะการ์ด 🥜 **ฉันแพ้ถั่วลิสง** (AAC)

### Interaction Workflow (หัวข้อ 3.2)

```
[User Action]  ชี้ (food_04) + พูด + ติ๊กตัวเลือก + การ์ดแพ้อาหาร
        │
        ▼
[Context Aggregator] ──รวม Slot ทั้งหมด──► [Actor: พนักงาน]  ถาม → ทวนออเดอร์ → แจ้งยอดชำระ + เวลาเตรียม
                                     └──► [Coach: ผู้ประเมิน] ความครบถ้วน · ความชัดเจน · ความสุภาพ · ความปลอดภัย
```

State Machine ของออเดอร์: `ordering` (เก็บข้อมูล) → `confirming` (พนักงานทวน รอยืนยัน) → `complete`

### ตัวเลือกบนหน้าจอ
| ตัวเลือก | ทำอะไร |
|---|---|
| แท็บสถานการณ์ | สลับ 1.1 / 1.2 / 1.3 (เมนู พนักงาน และภารกิจเปลี่ยนตาม) |
| โหมด ภารกิจ | สุ่มโจทย์ให้สั่งให้ตรง — ภารกิจแพ้อาหารจะบอกว่า "คุณแพ้อะไร" (พนักงานไม่รู้จนกว่าคุณจะบอก) |
| ตัวเลือกย่อย | Chip เลือก 1 ค่า (เนื้อสัตว์, ความเผ็ด, นม ฯลฯ) + Checkbox (ไม่ใส่..., แยกน้ำจิ้ม, เบเกอรี) — กดส่งพร้อมคำพูดได้ |
| เสียงในร้าน | "ดังมาก" = พูดอย่างเดียวอาจฟังไม่ชัด ลองชี้/ติ๊ก/พิมพ์ช่วย |
| ดู JSON payload | ดูข้อมูลที่ Context Aggregator รวมจากทุกช่องทางก่อนส่งเข้า AI |

## ใช้ Claude เป็น Actor + Coach (ไม่บังคับ)

```bash
npm install
set ANTHROPIC_API_KEY=sk-ant-...      # PowerShell: $env:ANTHROPIC_API_KEY="sk-ant-..."
node server.js
```
- ค่าเริ่มต้นใช้โมเดล `claude-opus-5` (เปลี่ยนได้ด้วย `CLAUDE_MODEL`) — Actor และ Coach เรียกแบบขนาน ใช้ Structured Output (JSON Schema)
- เปิด server-side refusal fallback (`fallbacks: "default"`) ไว้ให้แล้ว
- **Safety Guard ไม่พึ่ง LLM:** หลัง Claude ตอบ server ตรวจอาการแพ้ ราคา และลำดับ "ทวน → ยืนยัน" ซ้ำเสมอ ถ้า Claude ลืมงดวัตถุดิบที่ลูกค้าแพ้ ระบบจะแก้และเตือนเอง
- ถ้าเรียก API ไม่สำเร็จ ระบบจะใช้ Offline engine แทนโดยอัตโนมัติ

## โครงสร้างโปรเจกต์

```
server.js              Orchestrator Backend — /api/config, /api/turn, /api/debrief
src/scenarios.js       Domain Ontology: 3 สถานการณ์, เมนู, ตัวเลือก, วัตถุดิบ, สารก่อภูมิแพ้, ภารกิจ
src/order.js           Order State: Slot Filling, ราคา, คำอธิบายออเดอร์, ตรวจอาการแพ้, เมนูที่ปลอดภัย
src/nlu.js             Intent & Slot Extractor ไทย/อังกฤษ (เข้าใจ "ไม่ใส่...", "แพ้...", "มี...ไหม")
src/aggregator.js      Context Aggregator: รวม พูด + พิมพ์ + ชี้ + ตัวเลือก
src/actorEngine.js     Actor Agent (Offline) + Safety Guard + State Machine ทวน/ยืนยัน
src/coachEngine.js     Coach Agent (Offline) ประเมินรายเทิร์น
src/llmEngine.js       Actor + Coach ด้วย Claude (ตัวเลือก)
src/debrief.js         สรุปผล: Goal, Efficiency, Politeness, Clarity (+ Safety เมื่อมีอาการแพ้)
public/                หน้าเว็บ: แท็บสถานการณ์, ป้ายเมนู, ตัวเลือกย่อย, การ์ด AAC, ใบออเดอร์, โค้ช
test/                  ทดสอบตามตัวอย่างในเอกสาร — รัน `npm test`
```
