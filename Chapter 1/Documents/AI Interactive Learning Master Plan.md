# **AI Interactive Learning for Daily Life Communication Skills**

**Project Master Plan & Curriculum Architecture**

## **1\. Project Overview & Objectives (ภาพรวมและวัตถุประสงค์ของโครงการ)**

ระบบ **AI Interactive Learning for Daily Communication** มีเป้าหมายเพื่อสร้างแพลตฟอร์มจำลองสถานการณ์เสมือนจริง (Situational Simulation) ที่ช่วยให้ผู้เรียนสามารถฝึกฝนและพัฒนาทักษะการสื่อสารที่จำเป็นในชีวิตประจำวัน

จุดเด่นของระบบคือการรองรับ **Multimodal Communication** (การสื่อสารแบบผสมผสาน) ซึ่งเปิดโอกาสให้ผู้เรียนเลือกใช้วิธีการสื่อสารที่หลากหลายตามความถนัดหรือข้อจำกัดทางกายภาพ ประกอบด้วย:

* **การพูด (Verbal/Speech):** การออกเสียง ความชัดเจน และการใช้ระดับภาษา  
* **การชี้หรือสัมผัส (Gestural/Pointing/AAC):** การใช้ท่าทางชี้เมนูหรือเลือกไอคอนภาพแทนคำพูด  
* **การพิมพ์ (Textual):** การพิมพ์ข้อความโต้ตอบ  
* **การแสดงผลลัพธ์แบบ Real-time:** ระบบจะจำลองปฏิกิริยาของคู่สนทนาและประเมินผลสัมฤทธิ์ทันทีเพื่อให้ผู้เรียนปรับปรุงตัว

## **2\. Overall Curriculum Structure (โครงสร้างหลักสูตรภาพรวม)**

หลักสูตรแบ่งออกเป็นบทเรียนครอบคลุมทักษะการใช้ชีวิตประจำวัน ดังนี้:

* **Chapter 0: Introduction & Foundations (พื้นฐานการสื่อสารแบบ Multimodal)**  
  * การทำความเข้าใจช่องทางการสื่อสาร (Verbal vs. Non-verbal vs. AAC)  
  * การฝึกตอบสนองต่อสิ่งเร้าในสถานการณ์พื้นฐาน  
* **Chapter 1: การสั่งอาหารทั่วไป (General Food Ordering)** *(ขยายผลจากกรณีศึกษาร้านกาแฟ)*  
  * การสั่งเครื่องดื่มและเบเกอรี (Coffee & Beverage Shop)  
  * การสั่งอาหารตามสั่ง / ร้านอาหารทั่วไป (การระบุส่วนผสม, ระดับความเผ็ด, การแพ้อาหาร, และการปรับแต่งเมนู)  
* **Chapter 2: การซื้อของและการชำระเงิน (Shopping & Transactions)**  
  * การสอบถามราคา, การต่อรอง, และการเลือกซื้อสินค้าในซูเปอร์มาร์เก็ต  
  * กระบวนการชำระเงินและการขอใบเสร็จ/ใบกำกับภาษี  
* **Chapter 3: การสอบถามเส้นทางและการเดินทาง (Navigation & Transportation)**  
  * การถามทางคนในพื้นที่หรือเจ้าหน้าที่  
  * การใช้บริการระบบขนส่งสาธารณะ (รถไฟฟ้า, รถเมล์, แท็กซี่)  
* **Chapter 4: การติดต่อสื่อสารในสถานการณ์ฉุกเฉินและบริการ (Emergency & Services)**  
  * การขอความช่วยเหลือเมื่อหลงทางหรือเกิดอุบัติเหตุ  
  * การติดต่อเจ้าหน้าที่บริการลูกค้าหรือหน่วยงานรัฐ

## **3\. Deep Dive: Chapter 1 \- การสั่งอาหารทั่วไป (General Food Ordering)**

ในบทเรียนนี้ ผู้เรียนจะได้ฝึกฝนทักษะการสื่อสารที่ซับซ้อนขึ้นผ่านสถานการณ์จริง 3 รูปแบบ:

### **3.1 Learning Scenarios**

1. **Scenario 1.1: คาเฟ่และเครื่องดื่มเฉพาะบุคคล (Coffee & Beverage Shop)**  
   * *โจทย์:* สั่งเครื่องดื่ม ระบุประเภท, ขนาด, ความหวาน, และประเภทนม (นมวัว/นมโอ๊ต)  
   * *Multimodal Focus:* การชี้เลือกเมนูบนหน้าจอแท็บเล็ต \+ การพูดบอกระดับความหวาน  
2. **Scenario 1.2: ร้านอาหารตามสั่ง / ฟาสต์ฟู้ด (Quick Service Restaurant)**  
   * *โจทย์:* สั่งอาหารจานเดียว พร้อมระบุเงื่อนไขพิเศษ เช่น "กะเพราหมูสับ ไม่ใส่ถั่วฝักยาว เผ็ดน้อย พิเศษไข่ดาวสุกๆ"  
   * *Multimodal Focus:* การพิมพ์ข้อความหรือเลือกตัวเลือกย่อย (Checkbox Modifiers) \+ การพูดทวนออเดอร์  
3. **Scenario 1.3: ร้านอาหารที่มีข้อจำกัดด้านสุขภาพ (Dietary Restrictions & Allergies)**  
   * *โจทย์:* สั่งอาหารพร้อมแจ้งอาการแพ้อาหาร (เช่น แพ้ถั่วลิสง, แพ้อาหารทะเล) หรือขอเปลี่ยนวัตถุดิบ  
   * *Multimodal Focus:* การสื่อสารกรณีฉุกเฉินทางสุขภาพและการยืนยันความปลอดภัยกับพนักงาน

## **4\. System Architecture & Multimodal Pipeline**

สถาปัตยกรรมเบื้องหลังที่รองรับการฝึกฝนในทุก ๆ Chapter:

* **Frontend Layer (Next.js / React \+ Tailwind CSS):**  
  * หน้าจอแสดงผลแบบ Interactive ที่จำลองสภาพแวดล้อมจริง (เช่น เมนูดิจิทัล, เคาน์เตอร์ร้านค้า, แผนที่)  
  * รองรับ Multi-input Controls: ปุ่มกดไมค์ (Voice), ช่องพิมพ์ข้อความ (Text), และพื้นที่คลิก/แตะเลือกวัตถุหรือเมนู (Touch/Pointing Point)  
* **Multimodal Processing Layer:**  
  * **STT (Speech-to-Text):** แปลงเสียงพูดของผู้เรียนเป็นข้อความแบบ Real-time  
  * **Intent & Slot Extractor:** วิเคราะห์เจตนา (Intent) และดึงข้อมูลสำคัญ (Slots เช่น ชื่อเมนู, จำนวน, เงื่อนไขพิเศษ) จากข้อมูลที่ผู้เรียนส่งมาทั้งทางเสียง การชี้ และการพิมพ์  
* **Intelligence Layer (AI Agents):**  
  * **Actor Agent:** สวมบทบาทเป็นคู่สนทนาในสถานการณ์นั้น ๆ (เช่น บาริสต้า, พนักงานเสิร์ฟ, คนขับรถ) ตอบสนองตามความเป็นจริง หากข้อมูลไม่ครบจะแสดงพฤติกรรมถามซ้ำหรือแสดงความงุนงง  
  * **Coach Agent:** วิเคราะห์เบื้องหลัง ให้ Feedback ทันทีว่าการเลือกใช้ช่องทางสื่อสาร (เช่น ชี้อย่างเดียว vs พูดประกอบการชี้) มีประสิทธิภาพมากน้อยเพียงใด

## **5\. Development Roadmap (แผนการดำเนินงาน)**

* **Phase 1: Foundation & Chapter 0-1 (สัปดาห์ที่ 1 \- 3\)**  
  * พัฒนาโครงสร้างระบบ State Management และ Prompt Engine สำหรับควบคุมพฤติกรรม AI  
  * สร้าง UI สำหรับ Chapter 0 และ Chapter 1 (การสั่งอาหารทั่วไป ทั้งร้านกาแฟและร้านอาหารตามสั่ง)  
* **Phase 2: Multimodal Integration (สัปดาห์ที่ 4 \- 5\)**  
  * เชื่อมต่อระบบเสียง (Web Speech API / Whisper) และระบบรับพิกัดการสัมผัส/คลิก (Touch Event Payloads)  
  * พัฒนาระบบผสานข้อมูล (Context Aggregator) ให้รวมร่างข้อมูลจากหลายช่องทางได้พร้อมกัน  
* **Phase 3: Evaluation, Coach Dashboard & Scaling (สัปดาห์ที่ 6 \- 8\)**  
  * พัฒนาระบบประเมินผลของ Coach Agent และแดชบอร์ดแสดงผลสัมฤทธิ์ของผู้เรียน  
  * ขยายผลไปยัง Chapter 2, 3 และ 4 เพื่อให้ครอบคลุมทักษะการใช้ชีวิตประจำวันรอบด้าน

## **6\. Recommended Tech Stack**

* **Front-End:** Next.js (React) \+ Tailwind CSS \+ Lucide Icons  
* **Voice Processing:**  
  * STT: Web Speech API (Client-side low latency) หรือ Whisper API  
  * TTS: Web Speech Synthesis API หรือ ElevenLabs / Google Cloud TTS  
* **Back-End Orchestration:** FastAPI (Python) หรือ Node.js (Express/NestJS)  
* **AI Engine:** LLM รองรับ JSON Mode / Structured Outputs (เช่น Gemini API หรือ OpenAI API)  
* **Database:** PostgreSQL (เก็บบันทึกประวัติและผลการประเมินของผู้เรียน)
